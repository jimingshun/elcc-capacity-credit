# schemas目录

## 目录用途
保存由正式契约模型导出的版本化JSON Schema。

## 包含什么
数据集、导入批次、运行配置、运行清单、方法结果和产物清单Schema。

## 不应放什么
手工另写的平行字段定义、示例运行结果或临时草稿。

## 主要输入
`src/capacity_credit/contracts/`中的权威模型。

## 主要输出
供导入、CLI、报告、UI和外部集成校验的JSON Schema。

## 关键入口文件或命令
Schema导出和往返测试以实施计划、Taskfile及契约测试为准。

## 与其他目录的关系
字段语义归数据/方法/应用契约；本目录只保存机器合同。

## 修改后影响哪些测试
契约、Schema导出、往返、机器结果和受影响发布测试。

## Git提交规则
模型与生成Schema同一提交；禁止只改生成文件掩盖模型差异。

## 保留、归档和清理规则
受支持版本保留；弃用必须有迁移和兼容说明。
