# benchmark模块

## 目录用途
提供PRAS输入映射审计、外部结果解析和差异比较。

## 包含什么
纯Python映射、结果合同和比较逻辑。

## 不应放什么
Julia安装、PRAS运行时、生产风险计算或伪造外部结果。

## 主要输入
标准案例、外部轻量摘要、版本和误差证据。

## 主要输出
matched/explained_difference/unresolved/not_comparable比较结果。

## 关键入口文件或命令
由P5工具和`benchmarks/pras/`案例调用。

## 与其他目录的关系
独立于正式计算链；只比较，不拼接生产结果。 总体模块地图见[包说明](../README.md)。

## 修改后影响哪些测试
PRAS映射、比较、环境和发布阻断测试。 具体节点由[测试影响映射](../../../docs/testing/README.md)选择。

## Git提交规则
生产变更必须带所属领域最小反例；不混入无关格式化、生成结果或平行实现。

## 保留、归档和清理规则
本目录不保存运行实例、缓存、历史副本或用户成果。
