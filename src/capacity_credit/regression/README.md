# regression模块

## 目录用途
定义金标规范化、身份和差异合同。

## 包含什么
确定性字段过滤、清单和回归比较。

## 不应放什么
一键覆盖批准、原始大输出或生产计算副本。

## 主要输入
正式机器结果、输入/配置/脚本哈希和批准信息。

## 主要输出
可审计金标差异和发布阻断证据。

## 关键入口文件或命令
由T22/P5回归测试和发布检查调用。

## 与其他目录的关系
不修改生产结果，只比较受控身份。 总体模块地图见[包说明](../README.md)。

## 修改后影响哪些测试
金标、身份敏感性、批准和P5发布门测试。 具体节点由[测试影响映射](../../../docs/testing/README.md)选择。

## Git提交规则
生产变更必须带所属领域最小反例；不混入无关格式化、生成结果或平行实现。

## 保留、归档和清理规则
本目录不保存运行实例、缓存、历史副本或用户成果。
