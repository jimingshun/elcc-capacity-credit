# resources模块

## 目录用途
实现风光、储能、水电和联络线的物理时序行为。

## 包含什么
资源状态、调度约束、SOC/水量/联络线平衡和贡献。

## 不应放什么
容量价值求解、报告文案、测试专用放宽或资源间隐式能量转移。

## 主要输入
标准资源参数、时序、场景和调度策略。

## 主要输出
逐样本/逐时资源可用出力及物理诊断。

## 关键入口文件或命令
由engine和resource/application运行路径调用。

## 与其他目录的关系
solvers只通过正式资源运行接口评估候选系统。 总体模块地图见[包说明](../README.md)。

## 修改后影响哪些测试
资源单元、物理不变量、生产路径、组合和方法回归测试。 具体节点由[测试影响映射](../../../docs/testing/README.md)选择。

## Git提交规则
生产变更必须带所属领域最小反例；不混入无关格式化、生成结果或平行实现。

## 保留、归档和清理规则
本目录不保存运行实例、缓存、历史副本或用户成果。
