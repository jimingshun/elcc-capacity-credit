# solvers模块

## 目录用途
组织配对评估、等风险搜索、ELCC、EFC、MRI/rMRI和组合容量价值。

## 包含什么
方法适配器、搜索、稳定性和组合/边际求解。

## 不应放什么
资源物理副本、报告显示逻辑、状态机或未经证据的点估计。

## 主要输入
engine风险评估、资源运行接口、场景bank和方法配置。

## 主要输出
容量价值、搜索轨迹、收敛/稳定性和方法诊断。

## 关键入口文件或命令
由application正式运行服务调用。

## 与其他目录的关系
共享风险内核与方法适配分离，ELCC/EFC/MRI不各建一套可靠性模型。 总体模块地图见[包说明](../README.md)。

## 修改后影响哪些测试
解析、等风险、ELCC/EFC/MRI、组合、敏感性和生产调度路径测试。 具体节点由[测试影响映射](../../../docs/testing/README.md)选择。

## Git提交规则
生产变更必须带所属领域最小反例；不混入无关格式化、生成结果或平行实现。

## 保留、归档和清理规则
本目录不保存运行实例、缓存、历史副本或用户成果。
