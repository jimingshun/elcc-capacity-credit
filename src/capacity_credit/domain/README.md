# domain模块

## 目录用途
承载时间轴、系统、组合和诊断等不依赖基础设施的领域对象。

## 包含什么
稳定值对象、领域校验和组合结构。

## 不应放什么
文件持久化、CLI、报告渲染或外部进程调用。

## 主要输入
契约值和标准化数据。

## 主要输出
供内核、资源和应用服务共享的领域对象。

## 关键入口文件或命令
通过清晰类型和纯逻辑接口使用。

## 与其他目录的关系
位于contracts/data与engine/resources/solvers之间，避免反向基础设施依赖。 总体模块地图见[包说明](../README.md)。

## 修改后影响哪些测试
时间轴、系统边界、组合身份和诊断单元/性质测试。 具体节点由[测试影响映射](../../../docs/testing/README.md)选择。

## Git提交规则
生产变更必须带所属领域最小反例；不混入无关格式化、生成结果或平行实现。

## 保留、归档和清理规则
本目录不保存运行实例、缓存、历史副本或用户成果。
