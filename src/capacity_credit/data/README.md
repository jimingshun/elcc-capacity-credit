# data模块

## 目录用途
读取、登记、适配、校验、分级并冻结标准数据。

## 包含什么
I/O、registry、validation、grading和受控适配器。

## 不应放什么
求解器逻辑、用户原始数据副本或静默补0。

## 主要输入
只读原始文件、数据契约和适配规则。

## 主要输出
标准层、质量报告、来源台账和数据等级。

## 关键入口文件或命令
由application导入服务调用。

## 与其他目录的关系
输出供domain/scenarios/resources消费，不解释容量信用。 总体模块地图见[包说明](../README.md)。

## 修改后影响哪些测试
数据契约、导入、适配、质量、审批和真实模板字段测试。 具体节点由[测试影响映射](../../../docs/testing/README.md)选择。

## Git提交规则
生产变更必须带所属领域最小反例；不混入无关格式化、生成结果或平行实现。

## 保留、归档和清理规则
本目录不保存运行实例、缓存、历史副本或用户成果。
