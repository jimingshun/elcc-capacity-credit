# engine模块

## 目录用途
实现供需平衡、缺供事件、风险指标、在线统计、收敛和充裕度内核。

## 包含什么
正式可靠性计算内核和共享统计原语。

## 不应放什么
ELCC业务解释、文件状态机、UI或PRAS拼接。

## 主要输入
场景样本、资源出力、负荷和运行配置。

## 主要输出
样本级风险、LOLE/LOLH/EUE/NEUE及收敛证据。

## 关键入口文件或命令
由solvers和application通过稳定接口调用。

## 与其他目录的关系
resources产生物理出力，solvers组织等风险求解。 总体模块地图见[包说明](../README.md)。

## 修改后影响哪些测试
解析、性质、序贯、统计、资源生产路径和性能测试。 具体节点由[测试影响映射](../../../docs/testing/README.md)选择。

## Git提交规则
生产变更必须带所属领域最小反例；不混入无关格式化、生成结果或平行实现。

## 保留、归档和清理规则
本目录不保存运行实例、缓存、历史副本或用户成果。
