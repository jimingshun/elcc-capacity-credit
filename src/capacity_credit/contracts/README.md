# contracts模块

## 目录用途
定义版本化枚举、Pydantic模型、条件字段和Schema导出。

## 包含什么
数据集、导入、运行、结果、制品和治理契约。

## 不应放什么
业务计算、文件I/O、适配器或无版本字典。

## 主要输入
主责方法、数据和应用服务设计。

## 主要输出
规范化模型和JSON Schema。

## 关键入口文件或命令
所有层通过契约对象交换数据。

## 与其他目录的关系
被其他正式模块依赖，不能反向依赖具体实现。 总体模块地图见[包说明](../README.md)。

## 修改后影响哪些测试
契约、条件字段、Schema导出、往返和机器产物测试。 具体节点由[测试影响映射](../../../docs/testing/README.md)选择。

## Git提交规则
生产变更必须带所属领域最小反例；不混入无关格式化、生成结果或平行实现。

## 保留、归档和清理规则
本目录不保存运行实例、缓存、历史副本或用户成果。
