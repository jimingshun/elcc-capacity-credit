# locks目录

## 目录用途
保存指定操作系统和Python版本的解析后依赖锁。

## 包含什么
当前Windows/Python 3.12锁及生成说明。

## 不应放什么
跨平台猜测锁、下载包、wheel缓存或虚拟环境。

## 主要输入
上级依赖分组与受控解析工具版本。

## 主要输出
可重复安装的版本和哈希集合。

## 关键入口文件或命令
见上级[README](../README.md)和实施计划。

## 与其他目录的关系
被开发环境、CI和后续Windows发行构建消费。

## 修改后影响哪些测试
至少执行安装烟雾、`pip check`和包入口检查。

## Git提交规则
锁变更必须与依赖原因和生成环境一起提交。

## 保留、归档和清理规则
不在本目录保存下载缓存；弃用锁通过Git历史追溯。
